What it sees, and what it keeps

Only the post you click

XAIGC reads the post you ask it to answer, and nothing else on the page. It never reads your messages, followers or account details, and it cannot post for you.

Drafts are not stored

The post's text goes to the XAIGC server and on to OpenAI to write the draft. The server does not save that text or the draft it returns.

No API key of yours

You never paste an OpenAI key into the extension, so there is no key of yours to leak or to run up a bill.

Plain about the rest

What is kept, and why, is set out in the privacy policy in ordinary language.

Questions

Does XAIGC post for me?

No. It types a draft into the reply box and stops. You decide whether to post it, edit it or throw it away. If you prefer, switch to copy-only mode and it will not touch the page at all.

Do I need an OpenAI API key?

No. The writing happens on the XAIGC server. There is nothing to set up and no key to manage.

What does the free trial include?

20 generations with every feature, for each Google account. No card is needed.

What counts as a generation?

Each time XAIGC asks for new drafts. One request brings back several, and choosing "try another" to see the next one does not use a generation.

Can I use my plan on more than one computer?

Yes, up to the number of browsers in your plan. Sign in with Google on each one. If all your seats are taken you can move the license to the browser you are on.

Which languages does it write in?

English by default. You can have it match the language of the post instead, or always write in one of 17 languages.

What happens to the posts I reply to?

The text of the post is sent to the XAIGC server and to OpenAI so a draft can be written. It is not saved. The privacy policy has the details.

Which browsers are supported?

Google Chrome, version 111 or newer, on x.com and twitter.com.

Is XAIGC made by X?

No. XAIGC is an independent product of Unique Labs and is not affiliated with or endorsed by X Corp.
